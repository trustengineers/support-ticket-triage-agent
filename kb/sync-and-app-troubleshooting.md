# Tasks not syncing or the app crashes

Most sync problems are fixed by signing out and back in, which refreshes the local cache. On mobile, update to the latest version first: versions older than 4.2 can no longer sync.

If the desktop app crashes on start, delete the cache folder (Help > Open cache folder, then quit and delete its contents) and restart. If the problem continues, send us the app version, operating system and the time of the last crash so engineering can find the logs.
